# Speech Therapy Clinic Management System

A Java-based application developed as part of a Object-Oriented Programming practical assignment. The system is designed to support the management of a speech therapy clinic and centralize patient-related information and activities.

## Features

* **Patient Management** — Manage patient profiles and personal information.
* **Patient Records** — Maintain patient files, medical history, and clinical information.
* **Appointment Management** — Create and manage appointments between patients and the speech therapist.
* **Speech-Language Assessments** — Record assessment results, tests, questions, diagnoses, and observations.
* **Patient Follow-up** — Track patient progress and follow-up sessions.
* **Reports** — Manage assessment reports and consultation summaries.
* **Exercises & Workshops** — Organize exercises and activities related to patient treatment.

## Project Structure

The application is organized around several entities representing the different components of a speech therapy clinic, including:

* Patients and their records
* Speech therapists
* Appointments and consultations
* Assessments and diagnoses
* Tests, questions, and exercises
* Patient follow-up
* Reports and objectives

## Technologies

* **Java**
* **Object-Oriented Programming (OOP)**
* **IntelliJ IDEA**

## Project Context

This project was developed as part of a practical assignment in Object-Oriented Programming. Its main objective is to apply Java OOP concepts to the design and implementation of a real-world management system.
